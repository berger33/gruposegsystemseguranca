# Demonstração — portal do cliente
Este documento é fictício e deve ser publicado somente para uma conta de demonstração escolhida pelo curador.
Contratos, documentos e chamados são consultados no portal com acesso autorizado. Para abrir um chamado, descreva a necessidade na área de atendimento e acompanhe o protocolo. Não há valores, SLA ou cobertura definidos neste exemplo. O assistente não consulta automaticamente faturas ou dados atuais dos contratos.
