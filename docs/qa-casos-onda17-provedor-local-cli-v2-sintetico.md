**Limites de segurança:** `writeFile(..., { flag: 'wx' })` impede sobrescrita acidental pelo helper, mas não é WORM/object lock; um processo com permissão no host pode alterar arquivos. Recibo é objeto QA não assinado: atacante que altera recibo e bytes conjuntamente pode gerar SHA correspondente. Não há material de chave ou âncora independente, retenção, escopo de sessão/grant real, transação DB+objeto, inventário das outras 123 colunas candidatas, prova de URLs externas, PITR/RPO/RTO ou custos de provedor. Importar dados de QA **não** cria bytes de CLI v2 no produto nem habilita cliente final. Nenhuma alteração na API `src/server/cli-api.mjs` ou em `src/server/backup-api.mjs`.
